# Concept asset prompts

The mockup uses three original images generated with the built-in image-generation tool. They are
visual placeholders only and do not depict an existing Baldur's Gate location or character.

## Hero map transformation

> An original, ultra-wide isometric dark-fantasy city at dusk, transitioning gradually from a
> softly pixelated classic late-1990s computer-RPG rendering into a crisp, richly restored painted
> rendering. Ancient stone districts, tiled roofs, narrow streets, river, trees and warm
> torchlight; dark left-side negative space; antique gold, burgundy, charcoal and muted teal. No
> text, logo, watermark, recognizable game location, copyrighted character, UI or modern object.

## Animation portal

> An original mystical stone portal in a ruined dark-fantasy courtyard, with translucent amber
> and crimson energy echoes progressing from blocky sparse particles into smooth detailed flame
> and light motion. Painterly, isometric, nocturnal, premium and restrained. No text, logo,
> watermark, recognizable game location, copyrighted character, UI or modern object.

## Sprite study

> An original fantasy adventurer sprite study showing consistent isometric poses of the same small
> armored wanderer, progressing from coarse low-detail sprite rendering into finely restored
> painted detail. Dark workshop backdrop, parchment grid, antique-gold rim light, burgundy,
> charcoal and muted teal. No text, labels, logo, watermark, recognizable character or UI.
