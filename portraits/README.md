# Portraits BG2EE

Extraction directe des BMP inclus dans les BIF de l'installation BG2EE. Aucune conversion, compression ou mise à l'échelle n'a été appliquée.

- Séries de portraits : 95
- Fichiers : 285
- `grands/` : affichage grand format (suffixe `L`)
- `moyens/` : affichage moyen (suffixe `M`)
- `petits/` : affichage petit (suffixe `S`)
- `inventaire_portraits.csv` : dimensions, taille des fichiers, BIF d'origine et checksum.
