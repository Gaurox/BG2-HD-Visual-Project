# Limites, droits et réutilisation

> **Statut :** Métadonnées juridiques et techniques  
> **Dernière vérification :** 2026-08-27

## Droit d’auteur

Cette archive est une synthèse originale. Elle ne contient pas les PDF complets, les archives Beamdog, les symboles de debug, les images de jeu ni les ressources propriétaires de BG2:EE.

Les noms de produits, marques et ressources appartiennent à leurs détenteurs respectifs. Les URL permettent au lecteur de récupérer les fichiers depuis leurs diffuseurs officiels.

## Réutilisation

Les procédures et checklists originales de cette archive peuvent être adaptées à un projet. Les extraits de syntaxe, noms d’API et noms de fichiers servent à l’interopérabilité et à la compréhension technique.

Avant de redistribuer :

- une ressource du jeu ;
- un fichier Beamdog ;
- une archive Creature Process ;
- un fichier de debug ;
- du code communautaire ;

vérifier la licence ou l’autorisation correspondante.

## Limites techniques

- absence de SDK Beamdog exhaustif ;
- contenu interne de l’archive Creature Process non inventorié dans cette synthèse ;
- comportements moteurs non documentés possibles ;
- différences entre versions et plateformes ;
- certaines pages communautaires peuvent évoluer après la date de vérification.

## Principe de confiance

Une assertion critique pour une conversion massive doit être soutenue par au moins deux éléments parmi : documentation, inspection de fichier réel, implémentation d’outil, test automatisé et test en jeu.
