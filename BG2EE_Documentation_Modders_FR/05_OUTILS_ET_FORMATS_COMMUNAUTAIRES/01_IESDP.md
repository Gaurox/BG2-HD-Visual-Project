# IESDP - référence communautaire des structures Infinity Engine

> **Statut :** Communautaire de référence, non officiel Beamdog  
> **Dernière vérification :** 2026-08-27

## Rôle

L’Infinity Engine Structures Description Project vise à documenter le fonctionnement de l’Infinity Engine et à servir les auteurs de mods, de conversions et d’outils.

## Contenu

- formats de fichiers ;
- opcodes et effets ;
- actions et triggers ;
- tables IDS ;
- notes sur les ressources et conventions ;
- différences entre moteurs et jeux.

## Comment l’utiliser correctement

1. Vérifier la variante de jeu indiquée sur la page.
2. Vérifier la version du format, pas seulement l’extension.
3. Respecter les tailles, offsets, types signés et endianness.
4. Comparer avec un fichier réel extrait du jeu.
5. Vérifier le comportement dans Near Infinity.
6. Considérer les champs marqués inconnus comme réellement inconnus.

## Limites

L’IESDP est un travail de recherche communautaire. Une page peut contenir des incertitudes ou des informations historiques. Les mises à jour modernes sont visibles via son dépôt et son historique, mais chaque assertion critique mérite un test.

## Utilité pour BG2:EE

C’est la source principale pour les structures non détaillées par Beamdog : BAM, PVRZ, TIS, WED, ARE, CRE, ITM, SPL, DLG, etc. Pour un pipeline de traitement graphique, les pages BAM V1/V2 et PVRZ sont prioritaires.
