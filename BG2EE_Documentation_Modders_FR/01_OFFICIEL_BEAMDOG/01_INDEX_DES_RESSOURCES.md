# Index des ressources officielles Beamdog

> **Statut :** Officiel Beamdog  
> **Dernière vérification :** 2026-08-27

## Portail principal

Le portail Beamdog Files centralise des manuels, release notes et téléchargements supplémentaires. Pour le modding BG2:EE, les entrées importantes sont les suivantes.

## Release notes Baldur’s Gate Series

- **Version 2.0** : source officielle la plus dense pour les opcodes, triggers, actions, externalisations et le nouveau système d’interface.
- **Versions 2.0 à 2.3** : document consolidé incluant les ajouts 2.1, 2.2 et 2.3.

## Beamdog Creature Process

Archive officielle présentée comme un exemple montrant comment une nouvelle créature a été ajoutée aux Enhanced Editions de l’Infinity Engine. BG2:EE figure explicitement parmi les jeux concernés.

## Fichiers de debug

- **2.6.6.0 Win64** ;
- **2.7.3.0 Win64** ;
- **2.7.3.0 Linux 64 bits**.

Ces fichiers ne constituent pas un SDK. Ils sont surtout utiles pour symboliser et comprendre des crashs ou des appels natifs lorsqu’on travaille sur le moteur ou des extensions proches du moteur.

## Guides officiels complémentaires sur le forum

- **The New UI System: How to Use It** : activation du mode d’édition, `UI.menu`, polices et Lua.
- **M_*.lua files and BGEE.lua** : modification incrémentale de tables Lua sans écraser tout le fichier d’origine.
- **Annonce 2.7** : changements de stockage, modding mobile et correction d’indexation BIF.

## Ordre de priorité recommandé

1. Release notes 2.0.
2. Guide UI officiel.
3. Guide `M_*.lua`.
4. Annonce 2.7.
5. Beamdog Creature Process.
6. Fichiers de debug, uniquement pour les besoins natifs.
