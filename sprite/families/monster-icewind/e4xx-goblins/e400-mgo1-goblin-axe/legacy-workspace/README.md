# Gobelin à la hache — extraction native

Extraction de provenance pour l'animation `0xE400` / préfixe `MGO1`. Ne pas utiliser ce dossier
pour résoudre l'identité ou l'inventaire courant. Utiliser la ligne
`0xE400:body:base-resref:MGO1:MGO1` de
[`../../../../../index/sprite_families.csv`](../../../../../index/sprite_families.csv), puis les ressources liées de
`sprite_resources.csv`.

Les BAM et leurs frames RGBA ont été extraits sans modifier le jeu. `MGO1WK` contient la marche.
Les répertoires d'assets et de tests ont été sortis de l'arbre actif le 2026-08-27.
L'archive externe a été supprimée par l'utilisateur le 2026-10-11 ; ces assets ne sont
plus disponibles dans cette archive. Le manifeste et l'ancien job conservés ici sont
des index de provenance, pas des chemins vers des données présentes ni des jobs exécutables.
Pour une nouvelle production, partir de [`../../../../../README.md`](../../../../../README.md),
appliquer [`../../../../../FAMILY_APPEND.md`](../../../../../FAMILY_APPEND.md), puis le contrat
raster [`../../../../../XBR2X_RASTER_CONTRACT.md`](../../../../../XBR2X_RASTER_CONTRACT.md).
