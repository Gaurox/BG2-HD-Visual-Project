# Lot33 — comparaison de transparence

Même cycle, RGB/alpha issus de la même production ; normal=compagnon droit, lumineux=prémultiplié. Tests indépendants ; attendre disparition avant la deuxième commande. Le noir interne opaque peut apparaître en normal, selon la source ; aucune suppression automatique du noir. Le bon mode d’un vrai sort dépend de son consommateur natif.

## 01 SPBOOM

```lua
-- blended
C:Eval('CreateVisualEffectObject("Z33B01",Player1)',0)
-- normal
C:Eval('CreateVisualEffectObject("Z33N01",Player1)',0)
```
