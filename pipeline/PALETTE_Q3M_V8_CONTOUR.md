# Q3m V8 — couverture de contour optionnelle

- Extension V7 x2, couleur inchangée : profils 8/9, règle 3, palettes natives vivantes, I + B/F + dépendances exactes. Writer `scripts/palette_partner_registry.py`, reader `engine/InfinityEngine-Enhancer/source-patchee/src/iee/creature_sprite_x2.cpp`.
- Magic `IEECSXN\0`, version 8 ; header/resource/profile/cycles identiques V7. Par frame : header V7 568 octets ; ancien troisième octet réservé (`frameReserved[2]`, offset 11) = présence couverture 0/1 ; ajouter `<IB3x>` (taille stockée A / codec / trois zéros) avant les payloads. Ordre : I, F si présent, A si présent. Taille logique A = `4 * native_width * native_height` octets ; codecs 0 raw / 1 XPRESS_HUFF. A absent : taille/codec 0, couverture implicite 255.
- A = multiplicateur alpha uint8, arrondi `(alpha_native * A + 127) // 255` ; RGB inchangé si alpha résultant positif, RGBA remis à zéro si alpha nul. Ne modifie pas le LUT Q3m, les dépendances palette, les centres ou les cycles. Composition et upload passent par le même `frame_pixel`.
- Classes spéciales protégées : I `<3` fixe / `<4` rampes ⇒ A doit être 255 ; rejet avant publication. Longueurs/codecs/réservés invalides, troncature et budget dépassé : rejet. Identité catalogue SHA/CRC et lease de feuille inchangées.
- A décompressé conservé avec les métadonnées de shard, compté dans `resource_metadata_bytes` et le budget LRU de métadonnées 128 MiB ; plafond cumulé 128 MiB par feuille avant allocation. I/F restent lazy et comptés dans leur budget existant. `index_bytes` du catalogue reste le nombre de pixels I ; `registry_bytes` et SHA/CRC couvrent A aussi.
- Producteur alpha actuel CPU : `scripts/sprite_alpha_coverage.py`, gaussien sigma 0,65 pixel x2, intensité 0,8, minimum A=176 ; bande intérieure 2, parties fines rayon 1,5, support positif strictement conservé. Ombres/spéciaux inchangés ; silhouette calculée avec les indices opaques spéciaux inclus, édition limitée aux indices ordinaires. Clé = recette + SHA processor + dimensions + indices classés `min(I,3)` ; indépendante des couleurs. Aucun modèle neuronal appelé.
