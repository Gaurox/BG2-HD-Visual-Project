## Diagnostic v1 (mesures sur `ar1600-water-30fps-20260923-v1/dry/frames`)

| Mesure | Natif WTLAKE x1 | v1 installé |
|---|---|---|
| Netteté (gradient moyen) par image | 6,1–6,6, constante | ancres x4 4,9–13,3 ; intermédiaires ≈4,5 |
| Pas entre phases | régulier | 1,1–2,7 puis **4,4–8,9** à chaque ancre |

- Ancres x4 SeedVR produites **image par image** (workflow `SeedVR-Image`) : détail incohérent.
- Apollo lisse entre ancres ; restauration exacte des ancres → saut toutes les 0,4 s = rythme 2,5 Hz perçu.
- Apollo `apo-8` sur ce contenu : aucune ancre 1–5 restituée, doublons ; à 12× en une passe,
  doublons systématiques (plafond 8×). Flux DIS : explique ~25 % de l'écart entre images natives,
  direction qui s'inverse de ±8 px natifs → WTLAKE est un **miroitement**, pas une translation.
  **Ne pas utiliser d'interpolateur par flux (Apollo compris) pour WTLAKE.**

## Recette v2

Producteur : `pipeline/scripts/build_ar1600_water_30fps_v2_trial.py`
(`--stage prepare|interpolate|upscale|build|review`, nouveau dossier `--output` à chaque essai).
`RUN = maps/water-batches/runs/ar1600-water-30fps-20260923-v2`.

1. Source : 6 images natives `WTLAKE` / `WTLAKER` (64×64) du lot spatial (`overlays/groups/*/source-native`).
2. Interpolation **trigonométrique périodique** (zéro-padding FFT temporel 6→72, Nyquist scindé) à x1 :
   ancres exactes aux indices `0,12,…,60`, boucle fermée C∞. Netteté x1 6,0–6,8, pas 0,47–0,63.
3. SeedVR 7B INT8 convrot, couleur `none`, contexte 3×3 (192→768), **un seul chunk temporel**
   de 105 images : `[56…71] + [0…71] + [0…16]` ; crop central 256.
4. Raccord de boucle : phases 0–15 = mélange entre les deux rendus SeedVR de la même phase,
   **à variance préservée** (passe-haut gaussien périodique σ3, gain ≤1,6). Coupe franche
   mesurée 4,6 contre pas naturel 1,7 ; mélange linéaire simple = −25 % de netteté.
5. Atlas : **une page 4096** BC3 (`QLKV000` / `QLKV0R00`), 15 colonnes, pas 264, marge périodique 4.
6. WED : repart du WED spatial (`override-candidate-v3/AR1600.WED`, `00140DDF…`) ; slot1 → `QBLKV0`,
   72 phases, vitesse 1. Repli sans shader : 72/15 = 4,8 s (lent, pas faux).
7. Registre `requests/ar1600-water-30fps-20260923-v2/registry-v3.json` : AR0900 conservé,
   entrées v1 AR1600 retirées ; `frame_count 72`, `source_fps 30 = target_fps 30` → aucun demi-fondu.
   Force procédurale 0. Code moteur inchangé depuis 4f33823b ; seul le registre compilé change.
