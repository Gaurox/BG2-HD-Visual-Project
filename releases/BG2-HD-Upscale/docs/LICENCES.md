# Licences, attribution and redistribution status

## Current status

This alpha is not published yet. The project has adopted its intended community
distribution policy, but the separate clean-install lifecycle test, public
contact route and release-specific provenance record remain
required before the first online alpha.

| Material | Status |
|---|---|
| InfinityEngine-Enhancer source and local alpha bundle | MIT, copyright (c) 2025 Gabriel; bundled pending clean lifecycle validation |
| EEex and InfinityLoader | external prerequisite; not redistributed by BG2HD |
| Game executables and Steam files | never redistributed |
| HD maps and UI derivatives | free alpha permitted under the adopted community policy, subject to the provenance record |

The detailed machine-readable record is
`bg2hd/manifests/licenses-and-exclusions.json`. A public package must include
the applicable license texts, required attributions and a provenance decision
for every generated/derived asset. Availability in a local mod or game folder
is not permission to redistribute it.

Forbidden release content includes player saves, logs, personal paths, Steam
account/configuration files, game executables, development overrides, backups,
captures, source previews, x2 comparison assets, pending-QA maps and external
EEex/InfinityLoader binaries.

The binding release policy is [Distribution policy](DISTRIBUTION_POLICY.md).
